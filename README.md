# 📘 AdGuard Home en MikroTik y OPNsense

Este repositorio documenta diferentes formas de implementar **AdGuard Home** en entornos de red, con foco en MikroTik RB5009 y OPNsense.

## 📂 Versiones disponibles

- [Versión 1.0 – AdGuard Home en contenedor MikroTik](./v1.0/README.md)  
  Limitación: no muestra IPs reales de clientes.

- [Versión 2.0 – AdGuard Home en dispositivo externo (IP 10.5.50.2)](./v2.0/README.md)  
  Recomendado: visibilidad completa de clientes, estable y sencillo.

- [Versión 3.0 – AdGuard Home integrado en OPNsense](./v3.0/README.md)  
  Integración directa con Unbound, sin hardware adicional.

## 🎯 Objetivo

- Dejar un legado técnico que permita a otros replicar y mejorar estas configuraciones.  
- Mostrar ventajas y limitaciones de cada enfoque.
